# 04 美术素材清单（第一章）

## 1. 总体规范
- **画风**：手绘复古、钢笔排线 + 做旧纸纹、低饱和阴郁色调；沿用已出的 `art/palette.png`（palette v1）与 `art/style_sample_room_1080x1920.png` 的质感。题材改为 **14 世纪北方石砌古堡**：粗糙石墙、木梁、铁件、挂毯、羊皮纸、蜡烛光。不要维多利亚条纹壁纸、座钟、玻璃油灯（时代不符）。
- **恐怖表现**：不画血腥、不画怪物全貌；用“过多的眼皮”“自行蠕动的墨迹/线头”“空白的名字”“湿气与黑泥”暗示。
- **色彩用法**：暗琥珀 #C9A25A = 可交互/烛光；干血红 #7A2E25 = 关键线索/危险（克制使用）；沼绿 #1F2B22 = 井与暗部；骨白 #E8DFC8 = UI 文字。
- **画布**：竖屏基准 1080×1920（安全区：上 120px、下 260px 留给 UI/道具栏）；导出 PNG（背景可 JPG/WebP）。
- **命名**：`bg_r1_hall.png`、`item_rosary.png`、`char_edric_neutral.png`、`fx_ink_tendril_01.png`……全小写下划线。

## 4. 侦探主角形象要求（埃德里克·霍洛）
- **年龄**：37 岁，看起来 40 出头——风霜、疲惫，但眼神锐利。
- **体型**：身高中等偏高（约 180cm），瘦削、肩略宽、微微驼背（长年伏案抄写+赶路）；手指修长，指节有墨渍与旧伤。
- **面部**：长脸、颧骨明显、浅灰眼睛、深眼窝；短而不齐的深棕胡茬，鬓角早白；左眉一道旧疤。头发深棕、及耳、略乱。
- **服装与时代感（14 世纪中叶北欧/英格兰平民偏上）**：
  - 及膝深灰褐羊毛**连帽斗篷（hood + liripipe 长帽尾）**，下摆沾泥；
  - 内穿暗绿/苔绿色**羊毛外衣（cotehardie 简朴款）**，皮腰带；
  - 腰间挂：皮质**书写袋**（蜡板、铁笔、羊皮纸卷）、小匕首（只作工具，不用于战斗）；
  - 深色紧身裤 + 磨旧的高帮皮靴；
  - 颜色严格用 palette：斗篷 #4A3626/#2B2119，外衣 #3E4F3A，皮件 #7A5A3E，烛光高光 #C9A25A。
- **标志性道具**（必须清晰可辨）：
  1. **双联蜡板**（侦探手记，UI 的“手记”图标也用它）；
  2. 一盏**手提铁皮灯笼**（角片窗，暗琥珀光）；
  3. 手腕上缠着的**灰烛修会念珠**（他自己的那串，7 灰 1 黑，与布伦丹同款——暗示同源）；
  4. 襁褓残布改成的**围巾/领巾**，上面隐约有半个“闭眼”纹（伏笔，不要画得太显眼）。
- **立绘/表情状态**（半身立绘，透明底）：
  | 文件 | 状态 | 用途 |
  |---|---|---|
  | char_edric_neutral | 平静观察，微侧脸 | 默认 |
  | char_edric_think | 一手托下巴/拿蜡板，皱眉 | 线索板、推理 |
  | char_edric_press | 前倾、指向前方、眼神冷 | 审讯出示证据“拆穿！” |
  | char_edric_wry | 嘴角一侧上扬的冷笑 | 吐槽/错误时自嘲 |
  | char_edric_shaken | 瞳孔缩小、冷汗、退半步 | 恐怖事件 |
  | char_edric_relief | 闭眼呼气、握念珠 | 回复心烛 |
- **理智下降时的变化**（叠加层，可程序切换）：
  - 不安（40–69）：脸色更灰、眼下阴影加深、头发更乱；灯笼光变暗。
  - 动摇（20–39）：轮廓线开始“走墨”（线条抖动、溢出），影子比本人多出一道/方向错误，眼白泛黄，手上墨渍像在蔓延；领巾上的“闭眼”纹略微清晰。
  - 提供 `_s2`（不安）、`_s3`（动摇）两套差分，或单独的叠加层 `ovl_edric_ink_s3.png`。
- **尺寸**：
  - 半身立绘：**1024×1536**，透明 PNG，人物占画面高度 90%，头顶留 5%；
  - 全身剪影（过场/房间内小人，可选）：**540×1440** 透明 PNG；
  - 手记头像/存档图标：**256×256**；
  - 对话框头像：**384×384**（由立绘裁切）。
- **参考方向**：中世纪手抄本插图的线条 + 版画的明暗，不要现代侦探元素（不要礼帽、风衣、放大镜、烟斗）。
