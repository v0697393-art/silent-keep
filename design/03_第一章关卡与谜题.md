> 每个房间 = 一张 1080×1920 竖屏背景 + 若干热点；点击热点 → 特写/拾取/对话；底部道具栏；右上角“侦探手记”（线索/证据/线索板/推理入口）；左上角心烛（理智）。

### 审讯 int_osbert（教学）
- 开场：“大人，这个冬天，堡里没有来过任何客人。”
- 谎言 L1：“没有任何修士来过。” → 出示 **ev_rosary** → “这……这可能是哪个路过的乞丐丢的……”
- 谎言 L2：“我们从不招待外人，也没有访客记录。” → 出示 **ev_burnt_page** → 崩溃：“是夫人让我烧的！那位兄弟十一月三日来，说是来抄家谱……后来夫人说，他已经走了，什么都不许记。”
- 奖励：管家递上通往北塔的话：“门上那块石头……按家训转。老爷小时候念过：**眼闭，水静，钥沉，井默。**” → 手记新增“家训”，解锁 pz_crest。
- 出错：出示无关证据 → 管家迷惑，埃德里克自嘲；心烛 -3，可重试。

### 谜题 pz_crest（家徽门）
- 2×2 石盘，每块点击依次循环 4 个图案：闭眼 / 水纹 / 钥匙 / 井。
- 答案（与挂毯家徽 + 家训一致，阅读顺序左上→右上→左下→右下）：**左上 闭眼，右上 水纹，左下 钥匙，右下 井**。
- 初始状态：左上 井、右上 钥匙、左下 闭眼、右下 水纹。
- 完成：石盘下沉，门开，冷风吹灭所有蜡烛一秒后又自己亮起。→ 进入 R2。

## 心烛（理智值）系统
- 0–100，开局 100；下限 **20**（永远不会降到 20 以下，永无失败）。
- 下降：查看恐怖细节（一次性 -5/-10/-15）、错误推理/出示错证据（-3/-5）。
- 回复：每个房间一个回复点（壁炉/开窗/七烛烛架）、完整念珠；冷却制。章节切换回到至少 70。
- 表现分级：
  - **≥70 清醒**：正常。
  - **40–69 不安**：画面四角暗角、远处低语、手记字迹轻微抖动。
  - **20–39 动摇**：墨迹从画面边缘爬入；偶尔把 UI 文字中的一个词替换成“▇▇”（关键提示词不替换）；出现**无害幻视热点**（点击只有一句诡异文本）。
- 补偿设计：心烛 <40 时，部分隐藏文字更容易看到（如 R2 家谱 1312 处浮现半个字母“E”），作为第二章的伏笔——低理智是“另一种看见”，不是惩罚。

## 解法链（v1.1，必经步骤）
R1：长桌（蜡烛、面包）→ 壁炉取拨火棍、点燃蜡烛 → 燃烛照桌下得念珠 → 拨火棍拨灰得残页 → 拨火棍撬盔甲得曲柄 →（可选：看挂毯，家徽门给出半条提示）→ 审讯奥斯博特（念珠→s1，残页→s2）得家训 → 家徽门：闭眼/水纹/钥匙/井 → R2。
R2：抄本（笔记）、蜡笔画、墨水台（炭条/刮刀/鹅毛笔）→ 炭条+刮刀=炭粉，炭粉+鹅毛笔=显影刷 → 显影家谱原本 → **线索板 cb_cycle 四条连线 + 结论 dd_why_brendan（选“他发现了周期，被选为今年的祭品”）** → 编年史匣解锁，拨 **852** → 半份契约 + 井形钥匙 → 面包喂乌鸦得眼镜 → 眼镜读契约得牧杖纹封蜡 → 井形钥匙开楼梯门 → R3。
R3：井沿黑珠、铁链、（石棺）→ 曲柄装绞盘 → 审讯伊瑟尔达（黑珠→s1，家谱或石棺→s2，湿链→s3，封蜡→p1）→ 最终推理 [塞弗林神父 / 名字 / 井下] → 转动绞盘 → 章末过场。
