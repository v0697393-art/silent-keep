# 05 音乐音效清单（第一章）

## 风格
中世纪调式（多利亚/弗里吉亚）、修道院素歌、维奥尔/中世纪竖琴/风笛低音持续音、手鼓极少；恐怖靠**持续低音、失谐的人声、过近的耳语**，不靠尖叫与 jump scare。格式：OGG + MP3 双份，BGM 无缝循环，44.1kHz。

## BGM
| ID | 场景 | 描述 | 长度 |
|---|---|---|---|
| bgm_title | 标题 | 单人男声素歌哼唱 + 低音持续音，结尾一个音被“念错” | 1:30 循环 |
| bgm_r1_hall | 大厅 | 壁炉暖意下的维奥尔慢旋律，偶有不和谐泛音 | 2:00 循环 |
| bgm_r2_scriptorium | 缮写室 | 竖琴拨弦 + 羽毛笔沙沙节奏感，冷、清 | 2:00 循环 |
| bgm_r3_crypt | 墓穴井室 | 低音持续 + 远处多人低声合诵（听不清的名字） | 2:30 循环 |
| bgm_interrogation | 审讯 | 低速心跳般的鼓 + 持续弦，紧张 | 1:30 循环 |

| bgm_ending_ch1 | 章末 | 井下用主角嗓音念“埃德里克”，渐强又骤停 | 0:45 |

## 环境声（循环）
amb_hall_fire（壁炉噼啪、风从门缝）、amb_tower_wind（塔顶风、远处乌鸦）、amb_crypt_drip（滴水、链条轻响、井下极低的呼吸）。

## 音效
拾取、组合成功/失败、道具使用、门开（石盘下沉）、家徽石盘转动、转盘锁咔嗒、匣子打开、羊皮纸翻页、炭粉刷显影（沙沙+低语渐起）、乌鸦叫/扑翼、开窗冷风、蜡烛点燃/熄灭、绞盘转动+链条、井盖滑开、线索板连线成功（红线绷紧）/失败（线断）、证词条翻出、错误提示（低沉木声）、UI 点击。

## 心烛相关
- s2 不安：叠加层 amb_whisper_low（音量 30%）。
- s3 动摇：amb_whisper_near（左右声道交替的耳语，偶尔念出玩家刚查看的物品名）、BGM 轻微降调 -30 cents。
- 回复：sfx_sanity_restore（素歌一句 + 烛火稳定）。

## 语音（可选，先做占位）
不做全语音；仅做“哼声/叹息”类非语言音：埃德里克（嗯？/冷笑/喘息）、奥斯博特（抽泣）、伊瑟尔达（冷笑/崩溃笑）。

## 第二章新增（《血脉》，对应 data/chapter2.json v2.0）
> 风格沿用第一章的中世纪调式、素歌、持续低音，不用尖叫，也不用 jump scare。新的听觉母题是**摇篮曲**：艾琳德唱的“线轴转，银铃响，小羊睡，月亮闭眼”（四句，每句一个意象）。本章三首房间 BGM 都要藏进这条旋律的片段，并在章末完整出现一次。
> 格式、采样率同第一章（OGG + MP3/M4A，44.1kHz，BGM 无缝循环）。交付后请把 id 写进 audio/audio_manifest.json（files.<id>，dir/loop/src/duration），verify 只认清单里的 id。
> 新增共 **15 个 id**：BGM 4、环境声 3、音效 8。第一章已交付、本章复用的有 bgm_title、bgm_interrogation、bgm_clueboard、两个 stinger、全部 UI 音效（uiSfx）、sfx_window_wind（R6 小窗）和心烛耳语层，不需要重做。
